# Space Tab Page

Расширение для Google Chrome, которое заменяет стандартную страницу новой вкладки на персональную дашборд-страницу.

## Что есть в расширении

- **Ссылки по категориям**: отдельные режимы `Обычные` и `Рабочие`, редактирование категорий и карточек ссылок.
- **Гибкая сетка**: карточки можно перетаскивать, менять размер (`1x1`, `2x1`, `1x2`, `2x2`) и позицию внутри 4x4 сетки.
- **Трекер привычек**: ежедневные отметки, streak (текущий и максимальный), редактирование списка привычек и цветов.
- **Заметки**: быстрый список заметок, статус выполнения, создание/редактирование/удаление.
- **Погода**: текущая погода + краткосрочный и расширенный прогноз с выбором города.
- **Скорость сети**: быстрый тест пинга/скачивания и определение страны подключения.
- **Google Drive sync**: вход через Google и сохранение/загрузка данных (ссылки, привычки, заметки) в файл на Drive.
- **Blackout режим**: быстрый черный экран на весь монитор.

## Технологии и API

- `Manifest V3`
- `Chrome Identity API` (OAuth2)
- `Google Drive API` (backup/restore данных)
- `OpenWeatherMap API` (погода)
- `localStorage` (локальное хранение состояния)

## Установка расширения в браузер

### Google Chrome

1. Скачайте или клонируйте репозиторий в папку на компьютере.
2. Откройте страницу расширений: `chrome://extensions`
3. Включите режим разработчика (`Developer mode`).
4. Нажмите **Load unpacked / Загрузить распакованное расширение**.
5. Выберите корневую папку проекта (где лежит `manifest.json`).
6. Откройте новую вкладку — должна загрузиться страница `Space Tab`.
